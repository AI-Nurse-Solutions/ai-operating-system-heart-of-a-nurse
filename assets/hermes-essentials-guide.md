# Hermes Essentials Guide

## Directive v1.1 Community edition

**Status:** Source-controlled setup guidance for the optional Hermes desktop path. This guide is not a clinical system, institutional deployment, compliance certification, or proof that EDENA controls are mechanically enforced by Hermes.

**Current operator:** Robert Domondon. NAIO and NIN are project initiatives.

> Community use is limited to D0/D1 material: public, synthetic, or non-sensitive personal content. Do not enter PHI, patient-identifiable data, employer secrets, credentials, or regulated operational data.

## Start with the browser-first path

You do not need Hermes to use the available Community experience. Start with the SOUL Quiz, prompts, templates, and local files in a browser. Choose Hermes only when you want a desktop runtime that can work with explicitly approved local files and tools.

## A lean setup sequence

1. Download Hermes only from its official Nous Research source.
2. Review the model provider’s retention, privacy, and billing terms.
3. If you bring your own API key, set a low spending limit before the first request.
4. Grant access only to a dedicated no-PHI workspace—not Desktop, Documents, Downloads, or the full disk.
5. Keep approval prompts on and inspect every proposed command or file operation.
6. Test with synthetic content before using your own D0/D1 material.
7. Stop if the requested access, cost, data path, or action is unclear.

## Governance boundary

EDENA supplies advisory risk, data, and action boundaries. Those dimensions remain independent:

- **Risk:** Green, Yellow, Orange, Red-P, or Red-E.
- **Data:** D0 through D4.
- **Action:** Observe, Draft, Recommend, Prepare Action, Act With Approval, or Constrained Autonomy.

Green Community use supports Observe and Draft with D0/D1 material. Recommend begins at Yellow. Unrestricted autonomy is prohibited.

A prompt, SOUL file, or written rule can guide behavior; it does not by itself prove enforcement. Treat a control as implemented only when a named mechanism, control path, tested environment, and current evidence establish that claim.

## Before each session

- Confirm the workspace contains no PHI or employer-confidential material.
- State the task, audience, and allowed action mode.
- Ask for drafts rather than final decisions.
- Review factual claims and sources yourself.
- Save only what you intentionally choose to retain.
- Keep responsibility with the authorized human.
