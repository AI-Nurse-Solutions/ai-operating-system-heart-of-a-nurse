# Personal AGI for Nursing Roles

Design records for evolving Nurse AI OS into a persistent, personalized, agentic companion — a personal AGI — for different nursing roles, starting from the personal sphere.

- [`DESIGN.md`](DESIGN.md) — Sphere-First Design Doctrine v0.1: maps Hark-style capabilities (ambient hardware, "Handoff" computer use, persistent memory, proactive reasoning) onto NAIO, and records the sequencing verdict — personalized persistent memory in the personal sphere first, with agentic handoff practiced on no-PHI personal screen work before any clinical surface is even proposed.
- [`MODULES.md`](MODULES.md) — Module Architecture v0.1: one core (SOUL + memory fabric + trust ledger + EDENA ceilings) with six role-tuned sockets — Knowledge Base, Learning Academy, Projects, Data Analysis Engine, Market Signal Engine, and Guide — each anchored to an existing ecosystem asset and connected incrementally, one at a time, as a ledger event.
- [`mission-control-lite/`](mission-control-lite/) — the browser-local surface of core-plus-sockets: a **two-minute start** that drafts a minimal starter SOUL.md and first project map in one flow (pick 1–3 life areas; a student can stop there), sphere tabs that the full Life & Projects Quiz `naio-projects.json` export replaces when the nurse goes deeper, a module rail with honest per-socket status and role-tuned links, a gentle expand-later nudge after a month, local notes, and JSON backup. Single file, no server, no PHI; activates nothing.
- [`downloads/`](downloads/) — **one download**: `personal-agi-starter-v0.2.zip`, the `My-Personal-AGI/` bundle with Mission Control Lite and the Memory Fabric Kit pre-assembled (working `Memory/` records and sphere folders already created, kit library at `19-Memory-Fabric/`). The SOUL.md and project map are not in the ZIP — the two-minute start drafts them: open `index.html`, do the start, save the downloaded SOUL.md next to it, and day one is complete. Downloading installs nothing.
- [`memory-fabric-kit/`](memory-fabric-kit/) — Personal Memory Fabric Kit v0.1: the runnable starting point. A sphere-scoped vault layout, a trust ledger with explicit promotion/demotion rules, three starter handoff cards (draft-and-attest, no-PHI, capped action modes), and a monthly memory review with a PHI-leak self-audit. Copies into a nurse's existing `My-Nurse-AI-OS` vault; installs nothing.
- [`knowledge-base/`](knowledge-base/) — the **personal Knowledge Base v0.1 pilot**, live at personal scale: a Knowledge Pack manifest contract, a fail-closed deterministic validator, and a `library-lock.json` in which every pack is accepted by an explicit human decision — with one reference pack (*Governed AI Study Basics for Nursing Students*, honestly held at `draft` pending independent review). The public NIN Knowledge Commons remains proposed doctrine in [`knowledge-commons/`](../knowledge-commons/); this pilot activates no catalog, namespace, or retrieval service. See [`knowledge-base/README.md`](knowledge-base/README.md).
- [`data-engine/`](data-engine/) — the **personal Data Analysis Engine v0.1 pilot**, live at personal scale: closed, declared analyses (count, count-by, sum, mean, min, max — nothing the human didn't ask for) over the nurse's own no-PHI CSVs, with fail-closed intake inheriting the Phase 22 Outcomes Ledger screens (PHI-like, secret-like, and overclaim phrases all refuse), rendered deterministically into per-analysis reports with provenance digests and CI-guarded freshness. Results are adoption signals and learning evidence for the nurse's own judgment — never efficacy or performance claims, and never employer-readable. See [`data-engine/README.md`](data-engine/README.md).
- [`signals/`](signals/) — the **Market Signal Engine v0.1**, live: NAIO distillation records for external signals, each carrying role-tuned five-line briefs (student / staff / NP / leader / educator) rendered deterministically to [`signals/briefs/`](signals/briefs/) and guarded by CI. Judgment happens once, at distillation; the renderer adds no model-generated judgment — only a fixed template of headings, provenance labels, and boundary language. See [`signals/README.md`](signals/README.md).

These documents are design records. They do not activate hardware programs, EHR integrations, clinical memory, ambient sensing, or institutional authority.

*Agents propose. Humans judge. Nurses steward.*
