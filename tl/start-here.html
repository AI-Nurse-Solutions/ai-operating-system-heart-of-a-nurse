Opsyonal: idagdag ang Hermes sa ibang araw

Ang Hermes ay hiwalay at open-source na desktop agent mula sa Nous Research. Maaari itong gumamit ng local folders, reusable skills, at tools na inaprubahan mo; hindi ito kailangan para magsimula.

Gumagana ang SOUL Quiz at browser path sa phone, tablet, Chromebook, Mac, o Windows gamit ang ChatGPT o Claude. Ang opsyonal na local Hermes path lamang ang nangangailangan ng suportadong Mac o Windows computer. Rough guide ang computer mula sa nakalipas na limang taon na may 8 GB o higit pa; tingnan ang official Hermes documentation. Hindi ginagawang local ng local files ang processing ng cloud model.
