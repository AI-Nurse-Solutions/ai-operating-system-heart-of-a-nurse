# Nurse AI OS — Physician setup cheatsheet

Our purpose is to equip clinicians and people with healing, restorative, and stewardship roles to scale good. Governance is our method of care at scale: dignity, clear scope, privacy, human judgment, and accountable contribution. Personal AGI is an aspiration, not a claim of achieved AGI. Begin gently; one useful task is enough.

Educational/nonclinical starter, not an installer, credential, or clinical authorization.
EDENA: Not evaluated. A0 / no action. Prompt instructions are not mechanical enforcement.

## Presetup — download and keep together
- Complete the physician SOUL quiz; download physician-soul-review-draft.md.
- Download physician-starter-package.zip and extract it locally.
- Keep your personalized SOUL result alongside the extracted package. The ZIP is generic and does NOT include your quiz answers.
- Read README.md. Open dashboard.html and mission-control.html in your browser.
- These are manual offline templates, NOT the Hermes built-in dashboard or an installed Mission Control plugin. Export your notes before closing; unsaved edits are lost. No automatic sync, storage, enforcement, or agent execution.

## 1 — Check hardware and prepare a clean workspace
Visit https://hermes-agent.nousresearch.com/desktop and https://hermes-agent.nousresearch.com/docs/getting-started/platform-support . Check the CURRENT OS/CPU-specific download and installation instructions, available storage, network, and administrator/employer approval. Do not assume a hardware fit from this quiz.
Apple Silicon macOS is a primary path; Intel Macs require the documented alternative rather than the Apple Silicon bootstrap DMG. Windows installer and MSIX requirements differ; MSIX requires Windows 11 22H2+. Linux uses the documented terminal path; packaged desktop availability differs.
We do not assert a universal RAM or GPU minimum. Running a cloud model through a local agent differs from hosting a local LLM, which may need substantial RAM/VRAM and disk space.

Prefer a dedicated, updated laptop/desktop without personal or sensitive work records. If unavailable, start with a separate non-admin OS user and dedicated project folder; these reduce accidental exposure but do not equal a security sandbox.
Why clean is ideal:
1. Fewer personal photos, financial files, family messages, or credentials within accidental tool reach.
2. Less chance of mixing clinician, business, management, and private material.
3. A narrower, easier-to-review file and account permission surface.
4. No automatic exposure through a personal browser profile, logged-in sessions, or cloud sync.
5. Easier backup, recovery, audit, and removal of experimental files.
6. A clearer record of sources, drafts, decisions, and what the agent changed.
7. A smaller potential blast radius from errors or malicious instructions in a file or web page.
A clean device is NOT a guarantee of privacy, compliance, isolation, or security. Keep PHI and confidential personnel/business records out. Use encryption, screen lock, updates, minimal permissions, and backups. Never disable employer controls or reset a device without approval and backups.

## 2 — Create a Nous account; install Hermes Desktop
Visit https://portal.nousresearch.com/ . Start with Free if available and suitable, or the entry-level paid plan (currently named Plus, not Basic). Check live terms, rate limits, model/tool entitlements, and costs: https://portal.nousresearch.com/manage-subscription . Free does not promise all models or hosted tools. The base Hermes Desktop app is free/open source and does not require a Nous account; other providers can be used.
Download only from the official Hermes site. Expect an OS-specific installer or documented terminal path, first-launch setup, provider authentication/model selection, and permission requests appropriate to the features you enable. Grant only necessary permissions, keep approvals on, and test first with a harmless synthetic prompt. Do not bypass security warnings blindly.
Hermes is the execution/runtime and Desktop interface: conversations, files, tools, skills, memory, and profiles. Nurse AI OS supplies professional purpose, boundaries, coordination patterns, and stewardship. This package does not add validated EDENA enforcement or grant institutional authority. Hermes Agent is not the same thing as a Hermes-branded model.

## 3 — Select your model / bring your own brain
Use Hermes setup or model/provider settings to select Nous Portal or another supported LLM provider. Configure secrets only through official setup, never in a quiz, SOUL file, package, or chat. Provider billing and data-retention terms apply.
A local Hermes installation can still send prompts, attachments, and tool-derived context to cloud models or hosted tools. Check every route and destination; local-first is not automatically local-only.
Advanced users can connect a supported local LLM endpoint. Defer a sovereign setup until Nurse AI OS can help review hardware, model capability, tool routes, telemetry, memory services, licensing, updates, backups, and network boundaries. A local model alone is not proof of sovereignty, compliance, or clinical safety.

## 4 — Hand off to your Hermes Agent, then stop for review
Extract the package yourself. Attach the SOUL result plus README.md, dashboard.html, mission-control.html, SETUP-CHEATSHEET.md, and HANDOFF-PROMPT.txt (or the ZIP if your installation supports inspecting it). Paste HANDOFF-PROMPT.txt. Never attach secrets, patient or personnel records.
Ask for a read-only inventory and a bounded proposal; approve exact changes separately. Keep the existing profile unchanged until approval. Run a public-source or synthetic-data test and review the result. Installation is not institutional authorization; institutional integration, shared deployment, PHI, and clinical use require separate approvals and verified safeguards.

## 5 — A voluntary charter ceremony, then your agent partnership
Read STEWARDSHIP-CHARTER.md. Open stewardship-ceremony.html for a quiet reflection and optional acceptance. Download or print your self-generated commemorative certificate if desired. No credential, verified identity, assessed competence, membership enrollment, installation consent, or clinical authority is created. The certificate is a personal keepsake only.
Read AGENT-COMPANION-GUIDE.md. Ask the agent to be a questioning thinking partner or a bounded Chief of Staff preparing priorities and drafts. Customize pace, purpose, and boundaries through reviewed change proposals; do not assume memory storage or role isolation. Protect human relationships and time for restoration.

## First safe task
Prepare a synthetic interdisciplinary meeting agenda with three discussion topics, decisions requiring human judgment, and an unassigned action list. Do not email it, access hospital systems, or schedule anything.

## Stop if
Unexpected credential/file access, claimed verified credentials, proposed patient-specific care, automatic external actions, unexplained cloud routing, or requests to disable approvals. Review permissions and ask for a safer, narrower proposal.
