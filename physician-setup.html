Why we begin carefully

The clean workspace, provider review, human approval, and small synthetic test are acts of stewardship: ways to protect dignity and help your contribution grow without passing hidden risk to others. Local-first supports a durable working home; it does not promise privacy or sovereignty by itself.

1. Check Hermes hardware fit and prepare a clean computer

Visit the official Hermes Desktop download page and platform support matrix before installing. Check your operating system, CPU architecture, available storage, connection, and any employer installation restrictions. Do not assume the quiz confirms compatibility.

  • Mac: Apple Silicon is a primary supported path. Intel Macs need the documented alternative; the Apple Silicon bootstrap DMG does not support Intel.
  • Windows: check the current installer-specific instructions. MSIX requires Windows 11 22H2 or later; other installation paths differ.
  • Linux: follow the documented terminal path; packaged Desktop availability differs from runtime support.
  • Model hardware: no universal RAM/GPU minimum is asserted here. A cloud-model connection does not require hosting the LLM locally; a local model has separate RAM/VRAM and storage needs.

Why a “clean” laptop or desktop is ideal

Prefer a dedicated, patched device without your personal files, patient records, confidential business documents, or personnel records. This supports continuity, reusable skills, and a professional knowledge workspace while making the agent’s working area easier to inspect.

  1. Reduce accidental disclosure: fewer family photos, financial documents, personal messages, or secrets within tool reach.
  2. Separate responsibilities: avoid mixing private life, clinician work, business planning, and management material.
  3. Narrow permissions: fewer folders, accounts, and integrations to review.
  4. Avoid inherited access: do not import a personal browser profile, logged-in sessions, or unrestricted cloud sync.
  5. Simplify recovery: easier backups, rollback, and removal of experimental outputs.
  6. Improve traceability: a clearer record of sources, drafts, decisions, and file changes.
  7. Limit the blast radius: fewer valuable assets exposed to agent errors or malicious instructions in retrieved content.

A separate non-admin OS user and dedicated folder are a fallback, not an equivalent sandbox. A clean device alone is not secure or compliant: use encryption, updates, screen lock, backups, minimal permissions, and employer-approved controls. Do not wipe an existing machine or bypass institutional restrictions.

2. Create your Nous account and install Hermes Desktop

Go to Nous Portal. Start with Free if its available models and limits fit your needs, or the entry-level paid plan—currently called Plus, not “Basic.” Check current plans and entitlements before subscribing. Free does not include every model or hosted tool.

The base Hermes Desktop app is free and open source; a Nous account is optional if you use another supported provider. Model inference and hosted tools may incur separate costs.

What Hermes does for Nurse AI OS

Hermes is the agent runtime and Desktop interface for conversations, tools, files, skills, memory, and profiles. Nurse AI OS supplies the professional purpose, coordination patterns, review boundaries, and stewardship approach. The LLM is the reasoning “brain,” not the whole operating environment. Hermes Agent should not be confused with a Hermes-branded model. This package adds no validated EDENA enforcement or institutional authority.

What to expect when downloading

Use the official Hermes download, not a third-party mirror. Expect an OS-specific installer or documented terminal installation, first-launch setup, provider sign-in or configuration, model selection, and permission prompts for features you enable. Follow OS instructions, grant only needed permissions, keep command approvals on, and begin with a harmless synthetic prompt. Do not bypass security warnings without understanding them.

3. Bring your own “brain”—your LLM provider

Choose Nous Portal or another supported provider through Hermes setup or model/provider settings. Review capability, cost, retention, and data destinations. Configure credentials only through official setup—not in quiz answers, SOUL documents, the package, or chat.

Local agent ≠ local inference. A locally installed Hermes can send prompts, attachments, and tool-derived context to a cloud model. Hosted browsing, search, memory services, or other tools may create additional routes. Verify those routes before sharing anything sensitive; this pathway remains no-PHI.

Advanced: a sovereign setup later

Experienced users can connect a supported local LLM endpoint. If you want a “sovereign” setup, let Nurse AI OS help you review it later: hardware, model/tool capability, licensing, network egress, telemetry, memory, updates, and recovery. A local model by itself does not prove sovereignty, compliance, or clinical safety. Do not start with an unreviewed advanced configuration.

4. Give your SOUL result and package to your Hermes Agent

Extract the package yourself. Attach your downloaded SOUL result and the package files to Hermes chat; use the ZIP only if your installation can inspect it. At minimum provide README.md, dashboard.html, mission-control.html, SETUP-CHEATSHEET.md, and HANDOFF-PROMPT.txt. These contain no credentials or patient data.

Copy HANDOFF-PROMPT.txt from the package. It asks Hermes to read and summarize before making changes, preserve existing configuration, and stop for explicit scope-specific approval. Uploading the files is not permission to install, activate, overwrite, or connect anything.
