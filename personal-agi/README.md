# Personal AGI for Nursing Roles

Design records for evolving Nurse AI OS into a persistent, personalized, agentic companion — a personal AGI — for different nursing roles, starting from the personal sphere.

- [`DESIGN.md`](DESIGN.md) — Sphere-First Design Doctrine v0.1: maps Hark-style capabilities (ambient hardware, "Handoff" computer use, persistent memory, proactive reasoning) onto NAIO, and records the sequencing verdict — personalized persistent memory in the personal sphere first, with agentic handoff practiced on no-PHI personal screen work before any clinical surface is even proposed.
- [`signals/`](signals/) — NAIO distillation records for the external signals that shaped this design.

These documents are design records. They do not activate hardware programs, EHR integrations, clinical memory, ambient sensing, or institutional authority.

*Agents propose. Humans judge. Nurses steward.*
